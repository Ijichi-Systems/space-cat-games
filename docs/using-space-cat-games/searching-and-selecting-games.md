# Searching and Selecting games

To search and select games, navigate to the games page. \
![](<../.gitbook/assets/image (1).png>)

The search bar is used to find a specific game. For example, entering "WarioWare, Inc" will return "WarioWare, Inc.: Mega Microgame$".\
\
"Sort By" is used to sort game by alphabetical (A-Z, Z-A), or default order. \
\
"Random Game" selects a random game.&#x20;
