# Security Policy

## Supported Versions

Space Cat Games maintains security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 19      | :white_check_mark: |
| 18.3    | :white_check_mark: |
| 17.3    | :white_check_mark: |
| < 16    | :x:                |

## Reporting a Vulnerability

We take security seriously. If you discover a security vulnerability in Space Cat Games, please report it to us responsibly.

### How to Report

1. **Do not** open a public GitHub issue for security vulnerabilities
2. Email your report to the maintainers with details about:
   - Description of the vulnerability
   - Steps to reproduce (if applicable)
   - Potential impact
   - Suggested fix (if you have one)

### What to Expect

- **Initial Response**: We aim to acknowledge your report within 48 hours
- **Investigation**: We'll investigate and work on a fix
- **Timeline**: Security patches are typically released within 30 days
- **Credit**: We'll credit you for the discovery (unless you prefer to remain anonymous)

### Security Best Practices

When using Space Cat Games:

- Keep your Node version and dependencies up to date
- Use a recent version of your browser
- Report any suspicious activity or unexpected behavior
- Check the `CODE_OF_CONDUCT.md` for community guidelines

## Security Considerations

- This project is open source and hosted publicly
- Game files are served from the `/public/games` directory
- All dependencies are documented in `package.json`
- Service Worker (`sw.js`) is used for offline functionality

## Contact

For security inquiries, please reach out to the project maintainers through appropriate channels.
